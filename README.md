# Radio Player

Минималистичный плеер интернет-радио для macOS, живущий в строке меню.

## Возможности

- **Воспроизведение** HLS-потоков (`.m3u8`) через AVPlayer
- **Текущий трек** — название и исполнитель из метаданных потока отображаются прямо в меню
- **Копирование трека** — клик по строке с названием копирует его в буфер обмена
- **Управление станциями** — добавление, редактирование, удаление; список сохраняется между запусками
- **Системная интеграция** — управление воспроизведением из Control Center, Touch Bar и медиаклавиш
- **Горячие клавиши** в меню: `P` — play/stop, `Q` — выход

## Требования

- macOS 13 Ventura и новее
- Xcode Command Line Tools (`xcode-select --install`)

## Сборка

```bash
make        # собрать RadioPlayer.app в текущей директории
make run    # собрать и запустить
make install # установить в /Applications/
make clean  # удалить артефакты сборки
```

## Добавление своих станций

Откройте **Настройки** из меню приложения. Поддерживаются любые HLS (`.m3u8`) и прямые аудиопотоки по HTTP/HTTPS.

## Стек

Swift 6 · SwiftUI · AVFoundation · MediaPlayer · SPM + Makefile
